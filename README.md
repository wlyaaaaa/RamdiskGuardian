# RamdiskGuardian

- **这是什么：**照看只放可重建缓存的内存盘，检查空间和电脑内存，必要时按条件重建它。
- **我怎么用：**平时让守护任务运行；在“RAMDisk 与远程串流维护”窗口看状态，长任务可请 AI 暂停自动重建。
- **怎么知道正常：**状态检查显示新鲜的 `OK`，盘和必要目录都在；单看任务运行不能证明正常。
- **坏了怎么提醒我：**严重错误变化时会弹一次消息；一般警告只记入状态，不弹窗。
- **让 AI 做什么：**请 AI 查看健康状态与错误记录，查明是否需要恢复任务或缓存盘，并核对结果。

部署与恢复见 [操作说明](DEPLOY.md)；哪些缓存适合放进去见 [Z 盘使用说明](Z_使用说明.md)。
