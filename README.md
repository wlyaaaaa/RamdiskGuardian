# RamdiskGuardian

- **这是什么：** 照看 Z 盘这个内存盘。盘里只放能重建的缓存；它检查空间和电脑内存，必要时按条件重建内存盘。
- **我怎么用：** 平时不用管，守护任务自动运行。要跑很长的任务时，可以请 AI 先暂停自动重建。
- **怎么知道正常：** 请 AI 查一下状态：显示最近的 `OK`，盘和必要目录都在，就是正常。光看到任务在运行不算数。
- **坏了怎么提醒我：** 出现严重错误时弹一次消息；一般警告只记下来，不打扰你。
- **让 AI 做什么：** 查看健康状态和错误记录，判断要不要恢复任务或重建内存盘，修好后再核对一遍。

部署与恢复见 [操作说明](DEPLOY.md)；哪些缓存适合放进来见 [Z 盘使用说明](Z_使用说明.md)。
